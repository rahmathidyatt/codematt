# codematt — Master Blueprint

## Tujuan

Personal portfolio & digital lab Rahmat Hidayat. Utamakan pemahaman pengunjung dan kemudahan publikasi proyek lintas web, data, ML, otomasi, dan modernisasi.

## Cakupan pekerjaan ini

Brief meminta **Phase 0 dan Phase 1**. Phase 1 harus berjalan mandiri: Next.js App Router, strict TypeScript, Tailwind, font lokal melalui next/font, tokens, navigasi desktop/mobile, footer, tema, repository konten tervalidasi, rendering MDX, satu contoh proyek, dokumentasi dan pengujian.

Home dan indeks Work pada fondasi hanya menguji alur publikasi otomatis. Lab, About, Notes dan Contact memakai halaman fondasi yang jujur; bukan klaim Phase 2–4 selesai. Command palette, filter URL, gallery, Motion, Notes engine, OG dinamis, structured data lengkap, analytics dan audit Lighthouse berada di tahap berikutnya.

## Roadmap dan gerbang

0. Riset dan keputusan arsitektur sebelum kode.
1. Fondasi runnable, build lulus dan smoke test.
2. Home lengkap, explorer dengan search/filter/sort URL, case studies, About.
3. Lab, command palette keyboard, interaksi khas, gallery, Motion terukur.
4. Notes MDX, TOC, reading time/progress, prev/next, SEO/OG/sitemap/schema dan analytics opt-in.
5. Audit aksesibilitas, browser, responsive dan Lighthouse. Target 95 bukan hasil yang boleh diklaim sebelum diukur.

## Fakta konten

Contoh Code Reader didasarkan pada proyek yang disebut pemilik. Jangan mengarang angka, testimoni, akun GitHub, email, CV atau hasil eksperimen. Tanggal konten adalah tanggal penulisan case study, bukan tanggal peluncuran produk. Semua bagian yang belum diverifikasi ditandai di MDX. Proyek internal hanya memuat informasi yang aman untuk publik.
