## Tujuan

Data Lab menyatukan langkah awal pengolahan data: membuka file, memahami struktur, dan menemukan masalah kualitas sebelum analisis lebih jauh.

## Fondasi

Phase 1 berfokus pada unggah CSV dan Excel, pemilihan sheet, pratinjau, pemeriksaan tipe kolom, nilai kosong, duplikasi, serta identitas baris internal.

## Sesi portabel

Riwayat permanen di server tidak menjadi kebutuhan fondasi. Sebagai gantinya, checkpoint sesi dapat diekspor dan diimpor kembali agar pekerjaan dapat dilanjutkan secara portabel.

## Keputusan keamanan

Arsip checkpoint perlu membatasi ukuran file, jumlah anggota, dan total data setelah dekompresi. Nama path yang keluar dari direktori tujuan, symlink, serta anggota arsip tidak valid perlu ditolak.
