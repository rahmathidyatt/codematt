## Gambaran proyek

Code Reader berangkat dari kebutuhan membaca dokumen dengan cara yang lebih fleksibel. Pengguna dapat mendengarkan teks tanpa harus terus menatap layar.

## Masalah

Dokumen panjang tidak selalu nyaman dibaca sekaligus. Pengalaman membaca membutuhkan kontrol agar pengguna dapat berhenti, melanjutkan, dan kembali ke bagian yang penting.

## Pendekatan

Antarmuka dirancang untuk menerima PDF dan DOCX, menampilkan teks, serta menyediakan kontrol mulai, jeda, lanjut, dan berhenti. Pemilihan rentang halaman membantu membatasi bagian yang ingin dibaca.

## Keputusan teknis

Aplikasi menggunakan HTML, CSS, dan JavaScript. Pembacaan suara memanfaatkan kemampuan browser atau perangkat. Ketersediaan suara dan bahasa dapat berbeda di setiap perangkat.

Struktur proyek awal ditempatkan dalam folder `dist`, sehingga pengujian lokal dapat dilakukan menggunakan server HTTP sederhana.

## Batasan dan pengembangan

Dokumen hasil pemindaian membutuhkan ekstraksi teks melalui OCR. Dukungan OCR dan konsistensi suara antarbrowser perlu dibuktikan melalui pengujian tersendiri. Dokumentasi ini belum menyertakan hasil uji aksesibilitas atau performa.
