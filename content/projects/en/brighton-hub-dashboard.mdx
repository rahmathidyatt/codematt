## Context

Operational work uses separate tools for schedules, people data, activities, and documents. This dashboard aims to bring access to those tools into one place.

## Scope

Planned modules include floor-time schedules, birthday data, cooperation reminders, internal notes, training, and Smart Messenger needs.

## Incremental approach

Integration starts with the foundation and existing modules. Each workflow is checked before the next module is added.

## Open issues

Imports, page navigation, and Smart Messenger receipt integration have required fixes. This case study does not claim all these integrations are complete.

## Publication boundaries

This is a summary of the goal and development process. Agent names, birthday data, company notes, and operational documents are excluded.
