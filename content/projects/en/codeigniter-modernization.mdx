## Legacy context

Modernization starts with a CodeIgniter application requiring a structure and compatibility audit, plus fixes for blocking issues before visual redesign.

## Strategy

The initial priority is a local Docker environment and resolving startup blockers. The Reports module is the first bounded change so behavior can be checked in small steps.

## Target environment

The specified target includes PHP 8.4, MySQL 8.4 LTS, Docker Compose, and development in VS Code. Compatibility with the actual CodeIgniter version and dependencies must be demonstrated before the runtime target is considered final.

## Migration principles

- Preserve existing features and business processes.
- Separate bug fixes from large visual changes.
- Make small changes with clear test evidence.
- Record compatibility decisions and outstanding work.

## Status

The project is under local development and intended for a portfolio. No production deployment or complete migration of all modules is claimed.
